## Why use this site?

With current modes of communication between the researchers and the PI, we believed that displaying progress, data, and important information would be most optimized if we kept all records in a private website. This allows data visualizations (e.g., bar graphs, flow charts) to be interactive and avoids the need for downloading documents since they can all be displayed via a built-in viewer. This will also serve as good practice for the undergraduate researchers to deploy their coding skills and familiarize themselves with the R environment for data collection and analysis.

Of course, in regard to participant data, all direct identifiers (e.g., name and date of birth) and indirect identifiers (e.g., major and year of graduation) will **not** be presented on this website. Namely, we will be presenting:
 * A timeline that outlines all expected tasks throughout the duration of the project (this can be found in [Timeline](/timeline))
 * **Hard** due dates for each expected task, which is also included in the Timeline page
 * An archive of all previous activities
 
Within the archive, blog posts will be uploaded regularly that describes what was done during given timestamps as well as any necessary visualizations. For example, if we were to discover any meaningful findings from our data, we would present it with our own interpretations. We believe that this will help create more engaging, "recap" meetings with everyone up-to-date on the status of the project.
