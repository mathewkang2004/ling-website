# LLIMU Research Hub

This is the research project website for the LLIMU lab, built with **Hugo** and the **PaperMod** theme.

## How to Edit
1. Open the `.Rproj` file in **RStudio**.
2. Run `blogdown::serve_site()` in the console to preview changes.
3. Edit `content/_index.md` to update the homepage or graphs.

## Data Visualizations
* **Mermaid.js**: Used for live-rendered line charts and timelines. 
* **ggplot2**: Used for high-fidelity research plots (saved in `/static`).

## Tech Stack
* **Framework**: [Hugo](https://gohugo.io/)
* **Theme**: [PaperMod](https://github.com/adityatelange/hugo-PaperMod)
* **Environment**: RStudio / Blogdown
